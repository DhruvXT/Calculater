# Calculator App

A modern calculator built using HTML, CSS, and JavaScript. This project provides a clean and responsive interface for performing basic arithmetic operations, percentage calculations, keyboard input support, and error handling.

## Features
- Addition, Subtraction, Multiplication, Division
- Percentage Operations
- Keyboard Support
- Responsive Design
- Modern UI
- Error Handling

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
